# Changelog

All notable changes to thoughtBench will be documented here.

This project follows a pragmatic versioning scheme:
- v0.x = MVP phase
- v1.0 = feature complete + stable

---

## v0.1.0 — Foundation (MVP-1)
- Initial SwiftUI app
- SQLite persistence
- Chat UI scaffolding
- File import foundation
- Local-first architecture

---

## v0.2.0 — Core LLM Workbench (MVP-2)
- Local LLM integration
- Model manager
- Persistent model roots
- Per-message edit / retry / grading
- Fully usable offline
